# تقرير الدفعة الأولى (01): شاشة Splash وشاشة Onboarding

## الواجهات المنفذة
1. **شاشة Splash (`SplashScreen`)**:
   - شعار المنصة وتصميم الهوية البصرية الحركي البسيط.
   - اسم النظام "منصة إدارة النقل المدرسي SaaS".
   - عبارة الهوية والاطمئنان.
   - مؤشر تحميل ناعم مع انتقال سلس وتلقائي.
2. **شاشة Onboarding (`OnboardingScreen`)**:
   - 3 صفحات سحب تفاعلية توضح الميزات الأساسية:
     - الصفحة الأولى: متابعة رحلة الطالب اللحظية.
     - الصفحة الثانية: إشعارات الصعود والوصول.
     - الصفحة الثالثة: إدارة النقل بمرونة وأمان.
   - مؤشرات الصفحات التفاعلية (Page Indicators).
   - زر "التالي"، زر "تخطي"، وزر "ابدأ الآن" بالصفحة الأخيرة.
