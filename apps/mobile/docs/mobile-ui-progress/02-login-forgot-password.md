# تقرير الدفعة الثانية (02): تسجيل الدخول ونسيت كلمة المرور

## الواجهات المنفذة
3. **شاشة تسجيل الدخول (`LoginScreen`)**:
   - شعار النظام وهويته البصرية.
   - حقل إدخال رقم الهاتف أو البريد الإلكتروني.
   - حقل كلمة المرور مع إمكانيات الإظهار والإخفاء.
   - خيار "تذكرني" ورابط "نسيت كلمة المرور؟".
   - زر تسجيل الدخول الرئيسي مع معالجة حالات Loading و Error.
   - التنويه الرسمي بأن الحسابات مُنشأة مسبقًا عبر المدرسة (تجنب إنشاء حساب عام أو Google/Apple per specification).
4. **شاشة نسيت كلمة المرور (`ForgotPasswordScreen`)**:
   - حقل إدخال الهاتف أو البريد المعتمد.
   - شرح الخطوات بوضوح وحالة النجاح التفاعلية عند الإرسال.
   - التوجيه التلقائي أو اليدوي لزر إدخال الرمز OTP.
