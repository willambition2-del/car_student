# تقرير الدفعة الرابعة (04): الرئيسية لولي الأمر واختيار الطالب

## الواجهات المنفذة
7. **الرئيسية لولي الأمر (`ParentHomeScreen`)**:
   - تحية مخصصة باسم ولي الأمر وجرس الإشعارات التفاعلي.
   - بطاقة الطالب المختار حاليًا.
   - حالة الرحلة الحالية (في الطريق، وقت الوصول المتوقع 07:45 ص).
   - بطاقات الخدمات السريعة (تتبع الباص، بيانات الطالب، تغيير العنوان، طلب غياب).
   - قائمة آخر الإشعارات الحية.
8. **اختيار الطالب (`SelectStudentScreen`)**:
   - دعم وجود أكثر من ابن لولي الأمر في المدرسة.
   - اختيار الابن وتحديث كافة البيانات في التطبيق فورًا.
