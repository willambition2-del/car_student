# تقرير الدفعة الخامسة (05): الخريطة المباشرة وتفاصيل الرحلة

## الواجهات المنفذة
9. **الخريطة المباشرة لولي الأمر (`ParentLiveMapScreen`)**:
   - MapPlaceholder احترافي يدعم إعدادات Google Maps لاحقًا.
   - عرض موقع الحافلة الحقيقي مع الحفاظ التام على خصوصية بقية الطلاب (عرض حافلة ومسار الابن المختار فقط).
   - بطاقة سفلية بالمعلومات الحية: رقم الحافلة، اسم المسار، وقت الوصول المتوقع، وآخر تحديث.
10. **تفاصيل الرحلة (`ParentTripDetailsScreen`)**:
   - نوع الرحلة، رقم الحافلة، بيانات السائق والمشرفة.
   - نقاط الصعود والنزول والأوقات.
   - Timeline زمني متدرج للأحداث (انطلاق، وصول المحطة، الصعود، وصول المدرسة).

## الملفات المضافة
