# تقرير الدفعة السادسة (06): بيانات الطالب وسجل رحلاته

## الواجهات المنفذة
11. **بيانات الطالب (`StudentDetailsScreen`)**:
    - صورة الطالب، الاسم، الصف، الشعبة، المدرسة.
    - رقم الحافلة والمسار المعتمد، نقاط الصعود والنزول، وحالة اشتراك النقل المدرسي.
12. **سجل رحلات الطالب (`StudentTripHistoryScreen`)**:
    - تصفية بالتاريخ واليوم.
    - سجل الرحلات الصباحية والعودة مع شارات الحالة (صعد، وصل، نزل، غائب).
