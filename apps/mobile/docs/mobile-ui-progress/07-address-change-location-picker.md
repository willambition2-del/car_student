# تقرير الدفعة السابعة (07): طلب تغيير العنوان وتحديد الموقع

## الواجهات المنفذة
13. **طلب تغيير العنوان (`AddressChangeRequestScreen`)**:
    - اختيار نوع التغيير (دائم، مؤقت، نقطة صعود فقط، نقطة نزول فقط).
    - تحديد تواريخ البداية والنهاية، والسبب وأقرب معلم للمنزل.
14. **تحديد الموقع على الخريطة (`MapLocationPickerScreen`)**:
    - تحديد عبر GPS أو اختيار يدوي بعلامة قابلة للتحريك.
    - عدم السماح بحفظ الطلب دون تأكيد الموقع.

## الملفات المضافة
- `lib/features/parent/address_change_request_screen.dart`
- `lib/features/parent/map_location_picker_screen.dart`
