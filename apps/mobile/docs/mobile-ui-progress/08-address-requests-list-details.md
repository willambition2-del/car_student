# تقرير الدفعة الثامنة (08): قائمة وتفاصيل طلبات تغيير العنوان

## الواجهات المنفذة
15. **قائمة طلبات تغيير العنوان (`AddressRequestsListScreen`)**:
    - فلترة بحالات الطلب (جديد، قيد المراجعة، مقبول، مرفوض).
16. **تفاصيل طلب تغيير العنوان (`AddressRequestDetailsScreen`)**:
    - مقارنة بين الموقع القديم والجديد، وعرض ملاحظات إدارة النقل المدرسي والتطوير الخطي.

## الملفات المضافة
