# تقرير الدفعة العاشرة (10): إشعارات وملف ولي الأمر

## الواجهات المنفذة
19. **إشعارات ولي الأمر (`NotificationsScreen`)**:
    - تقسيم وحسبيات (رحلات، تغيير عنوان، غياب، نظام).
    - دعم الإشعارات المقروءة وغير المقروءة.
20. **الملف الشخصي لولي الأمر (`ParentProfileScreen`)**:
    - بيانات ولي الأمر وأبنائه.
    - إعدادات تفضيلات الإشعارات، لغة التطبيق، سياسة الخصوصية وتأكيد خيار تسجيل الخروج.

## الملفات المضافة
- `lib/features/notifications/notifications_screen.dart`
- `lib/features/profile/parent_profile_screen.dart`
