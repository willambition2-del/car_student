# تقرير الدفعة الحادية عشرة (11): رئيسية وقائمة رحلات المشرفة

## الواجهات المنفذة
21. **الرئيسية للمشرفة (`SupervisorHomeScreen`)**:
    - عرض رحلة اليوم، الحافلة، والمسار المكلفة به.
    - مؤشرات الاتصال بالشبكة و GPS وحالة المزامنة والعمليات المعلقة.
    - زر كبير لبدء الرحلة.
22. **قائمة الرحلات المكلفة بها (`SupervisorTripsListScreen`)**:
    - رحلات الصباح، العودة، المكتملة وحالة التنزيل المحلي للبيانات.
