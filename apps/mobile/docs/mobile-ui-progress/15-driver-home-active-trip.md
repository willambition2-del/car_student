# تقرير الدفعة الخامسة عشرة (15): رئيسية السائق والملاحة الحية

## الواجهات المنفذة
29. **الرئيسية للسائق (`DriverHomeScreen`)**:
    - الرحلة المكلف بها وقابليتها للبدء.
    - حالة GPS والسرعة الحالية والاتصال بالشبكة.
30. **شاشة الرحلة الحالية والملاحة للسائق (`DriverActiveTripScreen`)**:
    - خريطة الملاحة الحية وإرشادات الاتجاه للمحطة القادمة.
    - عرض السرعة بالكم/ساعة والمحطة القادمة والوقت المتوقع للوصول.

## الملفات المضافة
- `lib/features/driver/driver_home_screen.dart`
- `lib/features/driver/driver_active_trip_screen.dart`
