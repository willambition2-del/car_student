# تقرير الدفعة السابعة عشرة (17): رئيسية مسؤول النقل ومركز التشغيل المباشر

## الواجهات المنفذة
33. **الرئيسية لمسؤول النقل (`TransportManagerHomeScreen`)**:
    - مقاييس التشغيل: حافلات نشطة، رحلات اليوم، رحلات متأخرة، طلبات العناوين المفتوحة.
34. **مركز التشغيل المباشر على الهاتف (`TransportOperationsCenterScreen`)**:
    - خريطة تفاعلية كاملة لمواقع الحافلات والطلاب.
    - تفتيش مباشر: عند النقر على الطالب يظهر المسار والحافلة والسائق والمشرفة وحالة الرحلة، وعند النقر على الحافلة تظهر الحمولة وحالة GPS.

- `lib/features/transport_manager/transport_operations_center_screen.dart`
