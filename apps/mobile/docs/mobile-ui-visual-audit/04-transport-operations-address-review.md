- **مركز التشغيل الميداني التفاعلي**: تصميم شاشة تفتيش ورقابة حية تسمح بفتح دروج تفاعلية للطلاب والحافلات فور الضغط على أي نود، مع إظهار المسار الحالي، الحمولة، حالة الـ GPS، وبيانات السائق والمشرفة.
