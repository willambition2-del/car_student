## 3. ملخص الأنشطة المنفذة بحسب الأدوار

1. **ولي الأمر (Parent)**:
   - متابعة حية لرحلة الابن مع الحفاظ التام على خصوصية بقية الطلاب.
   - تقديم طلبات تغيير العنوان واختيار الموقع بمرونة ومتابعة الموافقة.
   - تقديم طلبات الغياب وتحديد خيار الاستلام الشخصي.
2. **مشرفة الباص (Supervisor)**:
   - شاشة تنفيذ ميدانية بأزرار ضخمة عالية التباين تناسب الحركة أثناء سير الحافلة.
   - زر التراجع الفوري (Undo)، تسجيل الوصول للمدرسة، وتنبيهات الأمان لتفريغ الحافلة.
   - طابور المزامنة الميدانية بدون اتصال بالشبكة (Offline-first support).
3. **السائق (Driver)**:
   - شاشة ملاحة مع توجيهات الحركة وقياس سرعة المركبة بالكم/ساعة.
   - بلاغات طارئة فورية وإرفاق صور الأعطال.
4. **مسؤول النقل (Transport Manager)**:
   - مركز رقابة وتشغيل تفاعلي كامل على الهاتف مع التفتيش اللحظي على الطلاب والحافلات.
   - مراجعة واتخاذ القرارات بشأن الطلبات والتنبيهات.
