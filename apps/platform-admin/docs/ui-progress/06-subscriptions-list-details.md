# تقرير الدفعة السادسة (06) - لوحة مالك المنصة (Platform Admin)

## الصفحات المنفذة
11. **سجل اشتراكات المدارس (`/subscriptions`)**:
    - جدول تتبع اشتراكات المدارس المستضافة، تواريخ الانتهاء، المبالغ السنوية المقبوضة، وتحديثات التجديد التلقائي.
12. **تفاصيل الاشتراك والتجديد (`/subscriptions/[id]`)**:
    - ملخص دورة الفوترة والتجديد وإتاحة نموذج التمديد السنوي المباشر.

## الملفات المضافة
- `src/app/(dashboard)/subscriptions/page.tsx`
- `src/app/(dashboard)/subscriptions/[id]/page.tsx`
