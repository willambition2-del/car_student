# تقرير الدفعة الثانية (02) - لوحة تحكم المدرسة

## الصفحات المنفذة
3. **الصفحة الرئيسية للمدرسة (`/dashboard`)**:
   - 4 بطاقات مؤشرات أداء حية (الرحلات النشطة، الحافلات المشغلة، الطلاب المنقولون، طلبات العنوان).
   - عرض الرحلات الجارية وتفاصيل صعود الطلاب.
   - إشعارات التنبيهات الميدانية الفورية وتفاصيل التأخير المروري.
4. **مركز التشغيل المباشر (`/operations`)**:
   - لوحة الخريطة التفاعلية المزودة بوضع التطوير وإرشادات الـ API Key.
   - درج تفتيش تفاعلي لاستعراض بيانات الطلاب أو الحافلات بنقرة واحدة.
   - شريط بحث وفلترة للمناطق والحافلات والطلاب.

## الملفات المضافة
- `src/app/page.tsx`
- `src/app/(dashboard)/layout.tsx`
- `src/app/(dashboard)/dashboard/page.tsx`
- `src/app/(dashboard)/operations/page.tsx`
