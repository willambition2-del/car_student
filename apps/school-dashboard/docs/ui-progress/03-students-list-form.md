# تقرير الدفعة الثالثة (03) - لوحة تحكم المدرسة

## الصفحات المنفذة
5. **قائمة الطلاب (`/students`)**:
   - جدول تصفية وبحث متقدم للطلاب مع الفلترة حسب الصف وحالة النقل والاشتراك.
   - أزرار تفاعلية للإضافة والتعديل والعرض المباشر.
6. **نموذج إضافة/تعديل طالب (`/students/new`)**:
   - نموذج تفاعلي مقسم إلى 3 أقسام رئيسية: البيانات الأكاديمية، بيانات ولي الأمر، وتخصيص الحافلة ومحطة السكن.
   - خيارات حفظ وتحقق وسلاسة في الإدخال.

## الملفات المضافة
