# تقرير الدفعة الخامسة (05) - لوحة تحكم المدرسة

## الصفحات المنفذة
9. **قائمة أولياء الأمور (`/guardians`)**:
   - جدول تفصيلي يضم أرقام الجوال والبريد الإلكتروني وعدد الأبناء المسجلين لكل ولي أمر.
   - خيارات تفاعلية للاتصال المباشر واستعراض ملف الحساب.
10. **تفاصيل ولي الأمر (`/guardians/[id]`)**:
   - ملخص ملف ولي الأمر وبطاقات الأبناء التابعة له ومواعيد الحافلات والمسارات.

## الملفات المضافة

- `src/app/(dashboard)/guardians/[id]/page.tsx`
