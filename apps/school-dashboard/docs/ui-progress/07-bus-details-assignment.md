# تقرير الدفعة السابعة (07) - لوحة تحكم المدرسة

## الصفحات المنفذة
13. **تفاصيل الحافلة (`/buses/[id]`)**:
    - ملخص مقاييس الأداء للحافلة وسجل الطاقم والمقاعد الشاغرة وجدول الطلاب المسجلين.
14. **توزيع الطلاب على الحافلات (`/buses/[id]/assign`)**:
    - مؤشر ملون لسعة الحافلة الاستيعابية وشريط التقدم النسبة المئوية.
    - قائمة تفاعلية لنقل وتخصيص الطلاب مع إظهار تحذير حرج لمنع تجاوز السعة القصوى للمقاعد.

## الملفات المضافة
- `src/app/(dashboard)/buses/[id]/page.tsx`
- `src/app/(dashboard)/buses/[id]/assign/page.tsx`
