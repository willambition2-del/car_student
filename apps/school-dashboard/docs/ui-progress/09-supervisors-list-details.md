# تقرير الدفعة التاسعة (09) - لوحة تحكم المدرسة

## الصفحات المنفذة
17. **قائمة المشرفات الميدانيات (`/supervisors`)**:
    - جدول بيانات مشرفات الحافلات والحافلة المخصصة ومؤشر حالة المزامنة الفورية مع السيرفر وتطبيق الموبايل.

    - ملف التكليف للمشرفة وسجل الرحلات المسجلة وحالة طابور المزامنة بدون إنترنت (Offline queue).
