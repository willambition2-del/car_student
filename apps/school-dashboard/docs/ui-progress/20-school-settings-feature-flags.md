# تقرير الدفعة العشرين (20) - لوحة تحكم المدرسة

## الصفحات المنفذة
39. **إعدادات المدرسة العامة (`/settings`)**:
    - نموذج تحديث بيانات الهوية والبريد والهاتف المعتمد وأوقات العمل والعملة الرسمية بالمنظومة.
40. **إعدادات ميزات المنصة (Feature Flags) (`/settings/features`)**:
    - واجهة تفعيل وتمرير مفاتيح الميزات المتقدمة (التتبع الحي، طلبات تغيير العنوان، المزامنة الميدانية، الإشعارات الفورية).

## الملفات المضافة
- `src/app/(dashboard)/settings/page.tsx`
- `src/app/(dashboard)/settings/features/page.tsx`
