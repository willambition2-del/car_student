# التقرير النهائي الشامل لوحة تحكم المدرسة (School Dashboard)
## منصة إدارة النقل المدرسي SaaS

---

## 1. ملخص الانجاز ونسبة الاكتمال
- **نسبة الإكتمال**: **100% (42 صفحة كاملة قابلة للتصفح والتشغيل)**.
- **عدد الدفعات**: **21 دفعة متتالية (صفحتان في كل دفعة)**.
- **التصميم واللغة**: تصميم عربي RTL فاتح بالكامل، متوافق مع كافة الشاشات والـ Responsive breakpoints.

---

## 2. المسارات والأحداث المنفذة بالكامل (42 صفحة)

1. `/login` - تسجيل الدخول لحسابات المدارس.
2. `/forgot-password` - استعادة كلمة المرور وإرسال الرمز.
3. `/dashboard` - الرئيسية ومؤشرات الأداء اليومية.
4. `/operations` - مركز التشغيل والرقابة المباشرة والخرائط التفاعلية.
5. `/students` - سجل الطلاب والبحث والفلترة.
6. `/students/new` - نموذج إضافة/تعديل طالب.
7. `/students/[id]` - تفاصيل الطالب والتخصيص الحافلي.
8. `/students/[id]/history` - سجل الرحلات السابقة للطالب.
9. `/guardians` - قائمة أولياء الأمور وحسابات التواصل.
10. `/guardians/[id]` - تفاصيل ولي الأمر والأبناء المسجلين.
11. `/buses` - إدارة أسطول الحافلات المدرسية وسعة المقاعد.
12. `/buses/new` - تسجيل حافلة جديدة وتعيين الطاقم.
13. `/buses/[id]` - تفاصيل الحافلة وطاقم القيادة والمشرفة.
14. `/buses/[id]/assign` - توزيع ونقل الطلاب وتحذيرات تجاوز السعة.
15. `/drivers` - طاقم السائقين المعتمدين ورخص القيادة.
16. `/drivers/[id]` - ملف السائق وسجل السلامة المرورية.
17. `/supervisors` - المشرفات الميدانيات والمزامنة الفورية.
18. `/supervisors/[id]` - ملف المشرفة وسجل طابور الـ Offline.
19. `/routes` - قائمة خطوط ومسارات النقل.
20. `/routes/new` - محرر المسارات وترتيب المحطات والأوقات.
21. `/routes/[id]` - تفاصيل المسار والجدول الزمني التقديري.
22. `/routes/[id]/assign` - توزيع طلاب الأحياء السكنية بالمسار.
23. `/trips` - سجل الرحلات الصباحية والعودة.
24. `/trips/[id]` - الخط الزمني للرحلة والمحطات المفتشة.
25. `/address-requests` - طلبات تغيير العنوان السكني.
26. `/address-requests/[id]` - مراجعة وتطابق خريطة السكن والقبول/الرفض.
27. `/absence-requests` - طلبات الغياب والاستلام الشخصي.
28. `/absence-requests/[id]` - مراجعة وتوثيق طلب الغياب.
29. `/payments` - رسوم النقل والاشتراكات المقبوضة.
30. `/payments/receipts` - سندات القبض الرسمية وسجل التحصيل.
31. `/notifications` - مركز الإشعارات والتنبيهات المدرسية.
32. `/notifications/new` - صانع وتنبيهات البث المباشر للهاتف.
33. `/reports` - مركز التقارير والإحصائيات.
34. `/reports/trips` - تقرير انضباط ومواعيد الرحلات التفصيلي.
35. `/reports/buses` - تقرير استغلال سعة المقاعد.
36. `/reports/financial` - التقرير المالي ومتحصلات الاشتراكات.
37. `/users` - المستخدمون وصلاحيات الموظفين.
38. `/roles` - مصفوفة الأدوار والصلاحيات المدرسية.
39. `/settings` - إعدادات ملف المدرسة والدوام والعملة.
40. `/settings/features` - تخصيص مفاتيح ميزات المنصة (Feature Flags).
41. `/support` - تذاكر الخدمة والدعم الفني.
42. `/profile` - الملف الشخصي وأمان كلمة المرور.
