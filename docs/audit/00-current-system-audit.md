# التدقيق الحالي للنظام

التاريخ: 2026-08-02

النظام Monorepo يضم NestJS/Prisma/PostgreSQL وFlutter ولوحتي Next.js. الموجود فعليًا هو المصادقة والإدارة الأساسية والرحلات والرسوم. الناقص فعليًا هو GPS وSocket.IO وFCM وOffline Queue؛ كما أن واجهات كثيرة تستخدم Mock Data.

عولج غياب فرض الأدوار، reset password العابر للمدارس، تجاوز سياق المدرسة، الربط العابر للمدارس، mass assignment، refresh، وتكرار الدفعات. المخاطر المفتوحة تمنع Staging والإنتاج حتى تنفيذ الخدمات اللحظية واختبارات E2E لكل دور ومدرستين.
