# توثيق إعادة تصميم تجربة ولي الأمر (Parent Experience)

## 1. الواجهة الرئيسية لولي الأمر (Parent Home Screen)
- **الترحيب والاختيار**: شريط ترحيبي بسيط يعرض اسم ولي الأمر، ومحدد أفقي نظيف في حال وجود أكثر من ابن/ابنة في المنصة.
- **شريط حالة نقل اليوم (Today's Transport Timeline)**:
  - مؤشر خطي زمني أفقي (بدأت الرحلة ➔ صعد الطالب ➔ وصل المدرسة) مع عرض التوقيت الفعلي المسجل لكل مرحلة.
  - **عدم استخدام التتبع الحي المباشر للباص على الشاشة الرئيسية** احترامًا للخصوصية وتقليل استهلاك البيانات والتركيز على الأحداث المفصلية.
- **شبكة الخدمات السريعة (2x2 Quick Actions Grid)**:
  1. طلب غياب طالب (Absence Request)
  2. تغيير موقع المنزل (Map Location Picker)
  3. بيانات الباص وطاقم الرحلة (Bus & Staff Specs)
  4. ملخص الرسوم والسندات (Fees & Payments Summary)
- **آخر الإشعارات التحديثية**: عرض مباشر لآخر تنبيهات صعود ووصول الطلاب.

## 2. تفاصيل الرحلة (Trip Details Screen)
- بطاقة معلومات الطالب والحافلة.
- بيانات السائق والمشرفة ونقاط الالتقاط والوصول.
- جدول زمني رأسي (Vertical Timeline) بالأحداث المؤكدة المسجلة (مثال: 07:18 ص صعد إلى الباص / 07:45 ص وصل المدرسة).

## 3. تحديد موقع المنزل (Map Location Picker)
- خريطة تفاعلية كعنصر رئيسي خلفي.
- ورقة تثبيت خيار الموقع (Bottom Sheet) تحتوي على: الحي/المنطقة، أقرب معلم، وصف البيت، زر موقعي الحالي، وزر حفظ الموقع.

## 4. شاشة طلب الغياب (Absence Request Screen)
- خيارات اختيار نطاق الغياب: رحلة الصباح، رحلة العودة، يوم كامل، عدة أيام.
- منتقي التاريخ (Date Selector).
- خيار الاستلام الشخصي من المدرسة (Self Pickup).
- زر إرسال موحد وواضح مع إشعارات مباشرة للمشرفة.

## 5. الرسوم والسندات والاشتراك (Student Specs & Financial Summary)
- ملخص مالي علوي: المطلوب، المدفوع، المتبقي.
- سجل سندات السداد والاشتراكات بدون مخططات إحصائية غير ضرورية.
