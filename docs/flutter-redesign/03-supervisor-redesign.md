# توثيق إعادة تصميم تجربة المشرفة الميدانية (Supervisor Experience)

## 1. الواجهة الرئيسية للمشرفة (Supervisor Home Screen)
- **بطاقة التشغيل العملية الموحدة**:
  - عرض الحافلة المسندة (رقم الحافلة، اسم المسار، وقت الانطلاق).
  - شريط العدادات: المتوقع، صعدوا، غائبون.
  - زر انطلاق رئيسي بارز: **"بدء الرحلة الآن" / "متابعة تنفيذ الرحلة الحالية"**.
- **شريط حالة الاتصال والمزامنة**: مؤشر اتصال شبكة خفيف وزر سريع للمزامنة المحلية بدون إزعاج.

## 2. تنفيذ الرحلة الميدانية (Active Trip Screen)
- **الهيدر التشغيلي**: اسم المسار، رقم الحافلة، الوقت، شارة حالة الشبكة (أجهزة محترفة).
- **شريط الملخص المباشر**: (المتوقع 28 | صعدوا 17 | غائبون 3 | متبقي 8).
- **بطاقات الطلاب المدمجة**:
  - صورة رمزيّة واسم الطالب والصف ونقطة الالتقاط.
  - شارة حالة واضحة.
  - **زرين كبيرين وعاليَي التباين**: "صعد" (Primary Navy) و "غائب" (Amber Danger).
  - عند النقر على "صعد": تتغير حالة الطالب إلى **"داخل الباص ✓"** ويختفي/يتعطل زر الصعود لتجنب الضغط المزدوج أثناء اهتزاز الباص.
- **تسجيل النزول (Drop-off Mode)**:
  - عند تسليم الطلاب أو الوصول، تظهر ورقة خيارات طريقة التسليم (Bottom Sheet) للتحقق من: استلام ولي الأمر، شخص مصرح له، أمام البيت، أو نقطة التجمع.

## 3. العمل بدون إنترنت (Offline Sync Engine)
- لا تظهر أي حوارات تنبيهية مزعجة أو تعطل سير العمل الميداني.
- شريط علوي/سفلي هادئ: `غير متصل — سيتم حفظ العمليات ومزامنتها تلقائيًا`.
- سجل المزامنة الميدانية يتيح زر "إعادة محاولة المزامنة" لجميع العمليات المعلقة بنقرة واحدة.
