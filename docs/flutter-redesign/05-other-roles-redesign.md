# توثيق إعادة تصميم تجربة مدير النقل والرقابة (Transport Manager Experience)

## 1. غرفة عمليات وتعديل مسارات النقل (Operations Center)
- **شبكة إحصائيات الأسطول**: الحافلات النشطة (18/20)، رحلات اليوم (36)، التأخيرات (1)، وطلبات العنوان الجديدة (2).
- **مركز الرقابة المباشرة**:
  - خريطة حية لتتبع جميع حافلات المدرسة.
  - شريط بحث وفلترة سريعة لاختيار حافلة أو طالب معين وعرض بطاقة تفاصيله الفورية.

## 2. مراجعة طلبات تغيير العنوان (Address Change Requests Review)
- بطاقات مراجعة طلبات السكن المرفوعة من أولياء الأمور.
- مقارنة العنوان السابق بالعنوان الجديد والمسافة المحسوبة.
- أداة تخصيص وتعيين الحافلة والمسار الجديد.
- أزرار القرار المباشر (قبول وتحديث المسار / رفض مع توضيح السبب).

## 3. تنبيهات النظام والاستثناءات (System Alerts Screen)
- قائمة التنبيهات الفورية (انقطاع GPS، تأخر حافلة عن الجدول، طلبات طارئة).
