# توثيق المكونات الموحدة والشاشات المشتركة

## 1. دليل المكونات (Widget Library Inventory)
- `AppTopBar`: شريط تنقل برميجي محتوي على العنوان والفرعي وزر العودة.
- `PrimaryButton`: أزرار بارزة بارتفاع 48px ولون كحلي مؤسسي.
- `SecondaryButton` & `OutlineButton`: أزرار ثانوية بإطار دقيق 1px.
- `DangerButton`: أزرار تنبيه وحذف خفيفة.
- `AppTextField` & `PasswordField`: حقول إدخال بحواف 12px وتسميات علوية وأيقونات إظهار كلمة المرور.
- `StatusBadge`: شارات حالة بنصوص وألوان لينة (soft colors) بدون صخب.
- `RoleBottomNavigation`: شريط التنقل السفلي التكيفي بحسب دور المستخدم الحالي.

## 2. الشاشات المشتركة (Shared Screens)
- `NotificationsScreen`: قائمة الإشعارات المصنفة بحسب الفئات (رحلات، عناوين، غياب، نظام).
- `GeneralSearchScreen`: محرك بحث شامل في الطلاب والحافلات والمسارات.
- `TechSupportScreen`: نموذج إنشاء تذاكر الدعم الفني ومتابعة التذاكر السابقة.
- `ParentProfileScreen` & `SharedProfileScreen`: شاشات الملف الشخصي وتفضيلات الحساب.
