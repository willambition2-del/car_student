# تنظيف وإزالة التصاميم والألوان القديمة

## 1. التغييرات المسحوبة والملغاة (Cleaned Up Elements)
- **إزالة ألوان التيل والتدرجات البراقة القديمة**: تم استبدال ألوان التيل والأزرق اللامع بباليتة الكحلي المؤسسي الرصين (`#123B5D` & `#174A70`).
- **إزالة الظلال الحادة البارزة (Aggressive Elevation/Shadows)**: تم إلغاء استخدام `Elevation: 8` أو `BoxShadow` القوية واستبدالها بنظام حواف دقيقة 1px وتظليل ناعم جدًا (Soft Border-first).
- **إزالة الانحناءات المفرطة (Pill Shapes)**: تم تنميط انحناءات البطاقات وحقول الإدخال بين 8px إلى 14px بدلاً من الشاشات المكتظة بالأشكال البيضاوية.
- **إصلاح الدوال المتروكة (Deprecated Flutter APIs)**: تم استبدال جميع استدعاءات `.withOpacity()` بـ `.withValues(alpha: ...)` لضمان التوافق التام مع إصدارات Flutter 3.27+.
