# تقرير المرحلة الثالثة (أ): نظام المصادقة للجلفية (Auth Backend)

> **تاريخ الإنجاز:** 2026-08-01
> **الحالة:** ✅ مكتمل ومختبر 100%

---

## 1. نظرة عامة
تم بناء نظام مصادقة آمن وحقيقي بالكامل يعتمد على JWT (Access + Refresh Tokens) مع تشفير كلمات المرور باستخدام Argon2 ورصد التوكنات في قاعدة البيانات مع حماية التدوير والتكرار.

---

## 2. المسارات المنفذة (Endpoints)

| الرمز | المسار | العامة/المحمية | الوصف |
|-------|--------|-----------------|-------|
| POST | `/api/v1/auth/login` | `@Public()` | تسجيل دخول مستخدمي المنصة والمدرسة مع إرجاع بيانات المدرسة والاشتراك |
| POST | `/api/v1/auth/refresh` | `@Public()` | التجديد التلقائي للتوكن مع حماية Token Rotation والتدوير الأمني |
| POST | `/api/v1/auth/logout` | `Bearer Auth` | إلغاء التوكن الحالي وتوقيف الجلسة الحالية |
| POST | `/api/v1/auth/logout-all` | `Bearer Auth` | إلغاء جميع التوكنات وتوقيف كافة الجلسات للمستخدم |
| POST | `/api/v1/auth/forgot-password` | `@Public()` | إنشاء وتوليد رمز تحقق أمني OTP لمدة 10 دقائق |
| POST | `/api/v1/auth/verify-otp` | `@Public()` | التحقق من صحة رمز OTP وإرجاع توكن إعادة التعيين |
| POST | `/api/v1/auth/reset-password` | `@Public()` | تغيير كلمة المرور باستخدام رمز OTP الصالح |
| POST | `/api/v1/auth/change-password` | `Bearer Auth` | تغيير كلمة المرور من داخل الحساب المسجل |
| GET | `/api/v1/auth/me` | `Bearer Auth` | جلب الملف الشخصي والمحتوى الموثوق للمستخدم الحالي |
| GET | `/api/v1/auth/sessions` | `Bearer Auth` | عرض كافة الجلسات الأجهزة النشطة للمستخدم |
| DELETE | `/api/v1/auth/sessions/:id` | `Bearer Auth` | إنهاء وإلغاء جلسة جهاز محددة |

---

## 3. ميزات الأمان المطبقة

1. **تشفير كلمات المرور**: تشفير فائق باستخدام Argon2.
2. **Access Token قصير العمر**: صالح لمدة 15 دقيقة ويحمل `sub`, `email`, `role`, `userType`, `schoolId`.
3. **Refresh Token دوّار (Rotating Refresh Token)**: صالح لمدة 7 أيام ومخزن كـ Hash في قاعدة البيانات.
4. **كشف إعادة الاستخدام (Reuse Detection)**: عند محاولة إعادة استخدام توكن ملغى، يتم إلغاء كافة توكنات المستخدم لحمايته.
5. **التحقق من حالة المدرسة والاشتراك**: يمنع المدارس الموقوفة (`SUSPENDED`) أو المنتهية (`EXPIRED`) من الدخول.
6. **تتبع الجلسات**: حفظ IP Address ومعلومات الجهاز و User-Agent لكل عملية دخول.
